Frequently Asked Questions

How does B2B Quant CNPJ Enricher compare to Serpro?

Serpro requires lengthy accreditation, state contractual commitments, and complex Brazilian payment gateways. B2B Quant provides instant international access via RapidAPI and Apify with zero bureaucracy and predictable pricing.

Is the Quadro Societário (QSA) data complete?

Yes, our API returns the full list of partners, qualification codes (administrators, shareholders, foreign representatives), and shareholding structure straight from the sovereign Federal Revenue database.

Can international fintechs use this API without a Brazilian entity?

Absolutely. International companies can subscribe directly in USD on RapidAPI or Apify without requiring a local Brazilian legal presence or CNPJ.

Does the API provide primary and secondary CNAE activities?

Yes, every record includes formatted economic activity codes (CNAE Principal and CNAE Secundários) with human-readable descriptions for automated B2B scoring.
