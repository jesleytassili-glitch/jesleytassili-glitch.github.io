Input Query Parameter: operationMode (string) • Required

Input Query Parameter: toolName (string) • Optional

Slug or MCP tool name of any of the 30 underlying @b2b-quant-apis engines (e.g., 'us-sec-edgar-filings-insider-radar', 'global-sanctions-pep-interpol-watchlist-screener', 'brazil-b2b-cnpj-qsa-lead-enricher').

Input Query Parameter: toolArguments (object) • Optional

Structured JSON arguments passed to the target B2B tool when operationMode is 'invoke_tool'.

Input Query Parameter: categoryFilter (string) • Optional

Filter the 30 B2B tools by domain category in 'list_catalog' mode ('ALL', 'FINANCE_KYB', 'GOVCON_PROCUREMENT', 'SECOPS_CYBER', 'HEALTHCARE_BIOTECH', 'BRAZIL_B2B_TAX', or 'ESG_LOGISTICS_GEO').

Input Query Parameter: apifyApiToken (string) • Optional

Optional Apify API Token to execute a live synchronous REST call against the target @b2b-quant-apis Actor during 'invoke_tool'. If omitted, returns a deterministic validated MCP execution envelope.

Input Query Parameter: maxTools (integer) • Optional

Maximum number of B2B tool definitions to return in 'list_catalog' mode (1 to 30).
