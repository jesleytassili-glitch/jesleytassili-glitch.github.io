## Frequently Asked Questions

### Why is RDAP superior to legacy WHOIS port 43?
RDAP (Registration Data Access Protocol) provides structured, machine-readable JSON directly from accredited sovereign registries, eliminating the text-parsing errors, formatting variations, and socket timeouts of legacy WHOIS.

### How does B2B Quant pricing compare to WhoisXML API?
WhoisXML API charges per query with expiring credit pools that quickly become expensive for active teams. B2B Quant offers predictable flat-rate monthly plans starting at $0 Free and $19/mo PRO.

### Can I use this API to detect phishing and brand squatters?
Yes. Our engine checks newly registered domains, calculates similarity scores against your core brand name, and returns registrar information for DMCA and UDRP takedowns.

### Does the API comply with privacy regulations (GDPR)?
Yes, it parses redacted and publicly available registrar data in full compliance with global data protection frameworks.
